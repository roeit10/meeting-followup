# האשף: מחברים את מערכת המשימות שלכם (פעם אחת)

המטרה: קובץ אחד, `context/meeting-followup.md`, כדי שמהפעם השנייה הסקיל ירוץ ישר מהתמלול.
בו: איזו מערכת משימות, איפה בדיוק (גיליון/לוח/רשימה), איזה שדה הוא מה, מאיזה Gmail שולחים, מי בצוות ומי הלקוחות.

> **איך שואלים (כלל קבוע):** כל שאלה דרך `AskUserQuestion`, בעברית, 2-4 אפשרויות ו-"Other".
> הצגה לאישור = "נכון" / "לתקן". **אף אחד לא עונה על שאלה פעמיים:** מה שנשאב רק מאושר.
> המשתמש כבר כתב בהודעה ("אני עובד עם מונדיי")? משתמשים בזה ולא שואלים.
> אם `AskUserQuestion` לא זמין (הרצה לא אינטראקטיבית): אותה שאלה כרשימה ממוספרת בטקסט, ועוצרים לתשובה.

לפני שמתחילים, משפט אחד למשתמש: "בפעם הראשונה אני מתחבר למערכת המשימות שלך. 3-4 שאלות קצרות, ומהפעם הבאה ישר לעבודה."

## שלב 2, השאלות (רק מה שחסר)

### שאלה 1: מערכת המשימות

`AskUserQuestion`: **"איפה אתם מנהלים את המשימות של הצוות?"**
אפשרויות: `מונדיי` · `Google Sheets (גיליון של גוגל)` · `ClickUp` · Other (Asana, Trello, Notion, Airtable...).
נמצא כבר משהו בשאיבה? הוא האפשרות הראשונה, עם "(מצאתי ב-business.md)".

| מערכת | toolkit ב-Composio | reference |
|---|---|---|
| Google Sheets | `googlesheets` | `google-sheets.md` |
| מונדיי | `monday` | `monday.md` |
| ClickUp / Asana / Trello / Notion / Airtable / אחר | `clickup` / `asana` / `trello` / `notion` / `airtable` / לפי `composio search` | `other-systems.md` |

### חיבור (לא שאלה, אלא אם חסר)

1. `composio connections list --toolkit <toolkit>`.
2. **ACTIVE אחד** → אומרים "<מערכת> מחוברת דרך Composio ✓" וממשיכים.
   **כמה ACTIVE** → שואלים איזה (קריאה קטנה מכל אחד כדי להציג שם/חשבון), ושומרים את ה-`word_id` בפרופיל.
3. **אין / EXPIRED** → `AskUserQuestion`: "צריך לחבר את <מערכת> ל-Composio. לפתוח עכשיו את חלון החיבור?"
   אפשרויות: `כן, תפתח` · `אחבר בעצמי ואגיד לך`.
   - "כן" → `composio link <toolkit>` (פותח דפדפן, ממתין לאישור). אומרים: "נפתח חלון בדפדפן. תתחברו ותאשרו, אני מחכה."
   - אחר כך שוב `connections list` עד ACTIVE.
4. **`composio` לא מותקן / לא מחובר לחשבון** (`command not found`, 401) → עוצרים: "Composio עוד לא מחובר אצלך.
   יש על זה שיעור במועדון (חיבור כלים, שיעור 5). אחרי `composio login` תכתוב לי 'המשך'."
5. **בדיקת קריאה:** קריאה אחת אמיתית מהמערכת (רשימת גיליונות / לוחות). נכשלה → אומרים מה נכשל, לא ממשיכים.

### שאלה 2: איזה גיליון / לוח / רשימה

מחפשים במערכת (לפי ה-reference) מועמדים לפי מילים כמו "משימות", "tasks", "CRM", "פרויקטים", שם העסק.
`AskUserQuestion`: **"באיזה <גיליון/לוח> נמצאות המשימות?"** עד 3 המועמדים הכי רלוונטיים (שם + מתי עודכן)
+ Other ("הדביקו לינק"). לגיליון עם כמה לשוניות, אחרי הבחירה: איזו לשונית (אם יש יותר מאחת שנראית רלוונטית).

ואז **קוראים** את שורת הכותרת / העמודות ועד 20 משימות, ומזהים לבד:

| אצלנו | מחפשים עמודה בשם | אם אין |
|---|---|---|
| משימה | משימה, שם, Task, Item, Name | שם הפריט / השורה הראשונה |
| אחראי | אחראי, Owner, Person, Assignee | "אחראי: ..." בהערות |
| עד מתי | תאריך יעד, Due, Deadline, Date | "עד מתי: ..." בהערות |
| סטטוס | סטטוס, Status, State | לא כותבים סטטוס |
| תלוי ב- | תלוי ב-, Depends on, Dependency | "תלוי ב: ..." בהערות |
| לקוח | לקוח, Client, Customer | שם הלקוח בתוך שם המשימה |
| הערות | הערות, Notes, עדכונים (Updates במונדיי) | חובה שיהיה מקום לטקסט; אין → שואלים איפה |
| דקה בתמלול | לא נכתבת למערכת | נכנסת להערות כ"סוכם בפגישה <תאריך>, דקה MM:SS" |

**סוג שדה התאריך קובע** (לפי ה-reference): טקסט → "לא נקבע" נכתב בשדה. תאריך אמיתי → ריק + "עד מתי: לא נקבע" בהערות.
**אחראי בשדה אנשים** (מונדיי, ClickUp): צריך משתמש אמיתי במערכת. איש צוות שאינו משתמש → השם בהערות.

### שאלה 3: סטטוס למשימה חדשה

`AskUserQuestion`: **"באיזה סטטוס לפתוח משימה חדשה מהפגישה?"** אפשרויות: הערכים שכבר קיימים בעמודת הסטטוס
(עד 3, לפי שכיחות) + Other. בעמודה בלי ערכים: `פתוח` · `לביצוע` · Other.
**בסטטוס של מונדיי/ClickUp מותר רק ערך שקיים בלוח** (לא יוצרים תווית חדשה).

### שאלה 4: מאיזה Gmail שולחים

`composio connections list --toolkit gmail`, ולכל חשבון ACTIVE: `GMAIL_GET_PROFILE` (`--account <word_id>`) כדי להציג
את הכתובת.
- נשאב חשבון מ-business.md והוא מחובר → לא שואלים, רק מציגים באישור.
  **לא מציגים את הכתובות של החשבונות האחרים** ("יש עוד חשבון מחובר, לא אגע בו" מספיק). הכתובות מופיעות רק כשצריך לבחור.
- **חשבון אחד** → מציגים באישור.
- **כמה** → `AskUserQuestion`: **"מאיזה חשבון Gmail לשלוח ולשמור טיוטות?"** אפשרויות: הכתובות. נבחר אחד ונשמר
  `word_id` שלו. מעכשיו **כל** קריאת Gmail עם `--account <word_id>`.
- **אין** → כמו בחיבור: `composio link gmail`.

### שאלה 5: צוות ולקוחות (רק אם חסר)

צוות או לקוחות בלי מייל בשאיבה → `AskUserQuestion` אחת: **"מי בצוות מקבל משימות במייל?"**
אפשרויות: השמות שנמצאו + "אני לבד, בלי צוות" + Other ("שם, תפקיד, מייל"). לקוח חדש שעולה בתמלול ולא בפרופיל →
שואלים בזמן הריצה ומוסיפים לפרופיל.

### אישור הפרופיל (תמיד)

מציגים את הפרופיל המלא בצ'אט ואז `AskUserQuestion`: **"זה הפרופיל. לשמור?"** `נכון` · `לתקן`.
"לתקן" → שאלה אחת מה לתקן (אפשרויות: מערכת · שדות · מיילים · צוות/לקוחות), מתקנים, מציגים שוב.
